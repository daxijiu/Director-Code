Director-Code Privacy Statement

Last updated: May 8, 2026

Overview

Director-Code is designed as a local editor application. It stores editor settings, AI provider configuration, API keys, and OAuth tokens locally through the application's normal settings and secret-storage paths.

AI Provider Requests

When you use AI features, Director-Code sends the prompt, selected context, tool results, and related request metadata to the AI provider that you configured. Supported provider families include Anthropic, OpenAI, Gemini, OpenAI-compatible services, and Anthropic-compatible services. Each provider processes data under its own privacy terms.

Telemetry and Online Services

Director-Code follows the VSCodium approach of reducing built-in telemetry. Some editor features, update checks, extension marketplace requests, safety metadata, extensions, or configured providers may still contact online services. You can review and adjust online-service settings inside the editor.

Credentials

API keys and OAuth tokens are intended to remain local to your device. Do not paste secrets into issue reports, public logs, screenshots, or shared workspaces.

Project Links

Privacy-related issues can be reported from the Director-Code issue tracker.
