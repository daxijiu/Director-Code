Director-Code Public Code Information

Last updated: May 8, 2026

Built-in Agent Behavior

Director-Code's built-in agent does not use GitHub Copilot public-code matching and does not maintain a public-code match filtering service of its own.

Provider Outputs

AI output is generated by the provider and model selected in your Director-Code settings. If a provider offers its own public-code matching, citation, retention, or output-filtering features, those features are governed by that provider's documentation and account settings.

User Review

You are responsible for reviewing generated code and text before use, including checking correctness, license compatibility, security, and project policy compliance.

Project Links

Source code and issue reporting are available from the Director-Code GitHub repository.
